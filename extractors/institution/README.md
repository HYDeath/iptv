# 高校与场馆

21 家机构各自作为一个抓取模块，统一归入「源管理 → 内置抓取模块 → 高校与场馆」，排在「海外」之后。每个模块只读取本机构的官网或官网明确嵌入的公开播放器；关闭某家机构不会连带关闭同类机构，也不应继续请求这家机构的上游。

节目仍进入主项目原有订阅，播放分组使用具体机构名称，节目名称前分别标记 **`[直播]`**、**`[回放]`**。这里的“回放”是可直接点播的官方录像，不是按电视播出时间查询历史节目的 catch-up 功能；活动预告不会提前输出为直播，已结束的流也不会继续当作直播。

## 目录与播放

机构定义集中在 `sources.js`，各官方站点的发现和取址逻辑位于 `providers/`。复用同一适配器的机构仍各自发现、各自开关；不会为了读取复旦而先抓取北师大和华科大，再从结果里过滤。

目录按官方当前状态刷新，发现数量是模块限定的样本范围，不代表机构全部视频资源。播放入口使用稳定的本机引用，播放时重新检查官方详情与权限并获取当前媒体地址，不把短效 CDN 签名写死在订阅中。HLS 的主清单、子清单、独立音轨、初始化片段和媒体分片经本机处理；MP4 保留 Range，供播放器拖动进度。主项目直接访问官方来源，不需要额外启动 `institution-live-lab` 或访问它的 1926 端口。

## 主项目实跑验收（2026-10-27，移除佳士得前）

以下为当时 22 个机构、68 条回放的历史验收记录。佳士得后来因部署端回放可用性不足被移除，当前收录 21 家机构，以前面的机构表为准；升级会自动清理其旧模块配置与抓取缓存。

使用临时数据目录运行主项目真实 `app.js`（本次端口 1947），只启用这 22 个机构模块（在隔离验收实例里手动打开，不改它们默认关闭的设置，也不改现有部署配置）。本轮主项目成功发现 **22 个机构、68 条公开回放、0 场实际在播活动**，与迁移前实验台样本一致。

- 主项目 `/m3u` 包含 68 条机构播放入口，节目名称均有 `[回放]` 标签并按机构分组；系统自制公告不计入这 68 条。
- 68 条均通过主项目本机播放链路的 FFprobe 与 **15 秒实际音视频解码**；多档 HLS 按最高分辨率视频及对应节目音轨核验，不只检查首个低档。
- 浏览器验证吉林大学 1080p MP4 实播 12 秒、总时长约 112 分钟，Range 可寻址且无媒体错误；富艺斯 720p HLS 实播 29 秒，无媒体错误。
- 主项目 `npm test` 全量通过。当前没有实际在播活动，本轮不能替代未来活动开播后的直播实网验收。

需要 Node.js、FFmpeg 和 FFprobe。先准备只启用待测机构的隔离主项目实例，再从主项目目录执行：

```sh
node scripts/probe-institution-main.mjs --base=http://127.0.0.1:1947 --out=/tmp/institution-main-verification.json
```

脚本读取主项目模块接口和订阅，使用订阅里的本机播放地址逐条验收，不直接调用实验台适配器或拿源站裸地址替代主链路；报告和订阅快照写到指定位置。该脚本会访问真实官方媒体，单独运行，不纳入离线 `npm test`。

68 条是移除佳士得前的验收结果，不代表“68 个直播频道”，也不是机构的全部视频资源。主项目实际条目数量随官方目录、模块开关和运行网络变化，每次复查均以当次报告为准。

## 权限与格式边界

易北爱乐的取址顺序为 `www.elbphilharmonie.de`（目录及演出详情）→ `www.ndr.de`（官方播放器）→ `ndr-progressive.ard-mcdn.de`（音乐会媒体）。机构请求复用主项目的代理请求层：已配置的 `HTTPS_PROXY`／`https_proxy` 或 macOS 系统 HTTPS 代理会用于目录、取址和媒体转发；未配置时仍使用部署机器原有网络。Docker 中的代理地址必须能从容器内访问，容器的 `127.0.0.1` 指向容器自身。

若易北爱乐抓取失败，模块详情中的最近错误会显示失败环节和域名。`ENOTFOUND`／`EAI_AGAIN` 表示名称解析失败，`UND_ERR_CONNECT_TIMEOUT`／`ETIMEDOUT` 表示连接超时，`ECONNRESET` 表示连接被中断；`HTTP 403` 表示官方入口返回访问拒绝。只能看到本机检查结果时，不能据此推断另一台部署机器的网络可达性。原有权限检查继续生效。

- 只使用官方页面、公开接口或官方页面明确嵌入的授权播放器，不使用社区 IPTV 清单或身份不明的转播源。宗教内容排除。
- 不绕过登录、付费、试看、观众注册、口令、验证码、DRM 或地区限制。国家大剧院匿名仅提供三分钟试看，本轮没有把它作为可用机构模块迁入。
- 中关村论坛遵循官方公开的匿名活动访客流程；只有主办方已启用公开回看的场次才输出，要求额外访问验证或注册的活动排除。
- 富艺斯当前提供的是预展和拍后回顾短片，尚未接入整场拍卖。模块没有竞买、注册或交易功能。嘉德 403、保利验证码等入口未继续探测，也未替换成归属未确认的相似域名。
- 吉林大学与广州大剧院个别官方媒体主机证书失效时，只使用已核验的同一官方主机 HTTP；不关闭 TLS 证书校验。
- 湖南省文化馆部分回放、上海论坛三条演讲使用 HEVC，播放器需要支持相应编码。H.264 与 HEVC 均保持官方格式，不转码。

## 台标与节目单

活动、讲座和独立点播视频不是电视台频道，官网节目海报不当作频道台标；没有核验合适的固定频道标时 `logo` 留空，由播放器显示自己的占位图，不引用第三方台标库或凭空画一个。

官方活动日期、预告、视频时长和已播视频目录不是全天电视节目编排，21 个模块的 EPG 均标“不适用”，不生成占位节目、不套用同名电视台节目单。详细登记见根目录 [EPG.md](../../EPG.md)。
