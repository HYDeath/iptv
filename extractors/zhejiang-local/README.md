三路线性电视归入「浙江」，默认启用。来源是各台在趣看平台托管的公开播放器：

| 频道 | 官方播放器 | 实测媒体 |
|---|---|---|
| 东阳新闻综合 | https://www.qukanvideo.com/cloud/h5/1681113308206040 | 1280×720，25fps，H.264/AAC |
| 衢江综合 | https://www.qukanvideo.com/cloud/h5/1700720505174325 | 1920×1080，25fps，H.264/AAC |
| 江山电视一套 | https://www.qukanvideo.com/cloud/h5/1623117710666335 | 1920×1080，25fps，H.264/AAC |

2026-10-28 本机验证：各路真实节目画面、12 秒音视频解码和直播序号增长均通过；主项目临时数据实例的订阅、台标与全代理分片也通过。短测不代表长期或所有网络出口都可用。

频道目录只保存稳定引用。每次播放先请求官方 `h5/w/detail`，核对频道 ID、原名、发布状态及公开访问权限，再调用播放器公开的 `channel/view/item/AntiTheft/playUrl`。签名计算来自当前官方 `app.42d315fd.js`，清单和分片限定到已实测的 `play-sh13.quklive.com` 及指定频道路径；兼容官方 `hls.quklive.com` 包装入口。遇到新的 CDN 或媒体结构，明确失败，重新核验后再适配。

签名不写盘，不固定在 M3U。主项目使用全代理，以部署机器的网络取清单与分片，会占用服务器带宽。官方关闭、改成登录/付费或当前时段不允许播放时，返回原因，频道保留在目录中。

官方播放器的频道封面字段为空，实时截图是节目画面；东阳新闻网也没有单独频道标。台标使用公开台标库备份，并已与官方直播台标核对，出处保存在 `logo-pack/index.json`。东阳与衢江的白字图铺了深色底，避免浅色界面看不清；运行时由本机提供，不依赖台标站。
