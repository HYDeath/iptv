# 百视通

`bestv-fj` 是默认关闭的备用模块，归入源管理的独立「百视通」面板。开启后在独立「百视通」分组输出七路专业频道；可在「加入订阅的频道」中选择完整 64 路里的其他频道。不会自动把这 64 路全部加入订阅。

| --- | --- | --- |

| 都市剧场 | 220 | 有 |

2026-10-29 核对咪咕官方各分类目录及项目其他固定模块，这七路没有现有来源；快乐垂钓、嘉佳卡通已有，因此默认不选。这个默认选择是固定的，之后用户添加其他来源时不会悄悄改动勾选。

## 来源

研究入口为用户提供的 `bst_LW2MB/index.php` 与频道表，原件和媒体验证保存在相邻 `tv-lab/bestv-fujian-live-lab`。主项目实现独立维护，不执行 PHP，也不依赖实验目录或本地 1936 服务。

- 匿名设备报备：`https://kylinapi.bbtv.cn/5g/v1/client-id-by-region`，按样本中的 SDK 请求签名取得 clientID。
- 官方目录及频道台标：同域 `/5g/v1/tvs`，台标来自目录 `icon` 指定的 `tvappstatic.bestv.com.cn/images/`。东南卫视在福建、卫视两组重复，元数据一致时只保留一次，矛盾时失败。
- 当前播放：`/5g/v1/tv/now/{id}`。只接受 ID、台名匹配、`state=live`、明确 `paid=false` 和足够有效期的响应。`contentIsFree=false` 与会员 benefit 字段同时出现过，不能把匿名能取到 URL 等同于长期免费承诺。
- 官方节目单：`/5g/v1/tv/programs/{id}`，返回跨日编排；按北京时间取今明两天，清理占位、重复及重叠。只为默认七路登记 EPG；其他 57 路没有本模块独立节目单，可由同时开启的已有来源提供同名节目单。

目录允许范围为此前实际解码通过的 64 个 ID，旧新疆卫视 ID 205 的 API 为 404，排除；ID 214 正常。目录后来新增的其他频道不自动收录。宗教频道不收录。TLS 证书校验保持开启；官方停用、付费或未知结构会失败，保留失败原因供源管理查看。

## 取流与续签

订阅输出 `/relay/bestv-fj-<id>.m3u8`。每次播放器刷新直播清单都会调用本模块：clientID 最多缓存 420 秒，播放入口最多缓存 120 秒且预留至少 30 秒余量；实时清单每次都读取。CDN 在缓存期内提前拒绝入口时立即重新获取，API 返回 401/403 时重新报备一次，仍失败就结束，不返回过期清单。

模块直接返回已经校验的实时媒体清单，相对分片由主项目改成绝对地址。媒体限定到 `fjnetv<数字>.live.bestvcdn.com.cn` 下当前频道的签名目录，拒绝跨频道、外部主机、加密、点播及未知清单结构。签名、clientID 和完整播放 URL 不写入磁盘频道缓存或错误描述。

默认只转发清单，播放器直连视频分片，因此服务器与播放设备都要能访问百视通。`?relay=2` 订阅可切换到主项目现有全代理模式。全代理会占用部署机器的媒体带宽。地区、运营商、平台状态和播放器兼容性仍可能影响播放；自动更新入口也不能消除所有网络故障。

## 验证

```sh
node scripts/test-bestv-fj.mjs
node scripts/test-bestv-fj-epg.mjs
node scripts/build-epg.mjs bestv-fj --out /tmp/bestv-fj.xml
npm test
```

测试夹具裁剪自 2026-10-29 实际官方目录和节目单，播放地址使用合成签名目录。验证默认开关、64 路选择、目录停用与变化、媒体边界、播放和 clientID 过期刷新、CDN 提前失效、付费拒绝及官方节目单处理。

台标已实际下载、检查并生成内置备份。平台的生活时尚图标为白字透明图，浅色界面文字对比度较低，保留其官方样式。

主项目隔离实例七路均通过 8 秒音视频解码，全代理抽查多彩文体4K 也通过。多彩文体4K 经本机清单入口实际连续解码 **8 分 30 秒**，墙钟 518 秒；34 次独立清单采样均为 200，观察到 6 组签名目录，媒体序号由 179328575 增至 179328625，FFmpeg 无错误输出。短期实测已跨过 120 秒播放地址缓存和 420 秒 clientID 缓存窗口；尚不能据此保证跨运营商或全天长播。详细记录保存在实验目录 `reports/main-long-play.json`。
